# 📺 قوائم IPTV العربية محدثة تلقائياً

مشروع للحفاظ على قوائم القنوات العربية المباشرة محدثة دائماً عبر التحديث التلقائي من موقع ELAHMAD.

## ✨ المميزات

- 🔄 **تحديث تلقائي كل 30 دقيقة** عبر GitHub Actions
- 📺 **301 قناة عربية** من مختلف الدول العربية
- 🎬 **روابط HLS حقيقية** مفكوكة ومحدثة
- 🌍 **18 فئة** من القنوات (سعودية، مصرية، قطرية، إماراتية، إلخ)
- 💾 **قوائم M3U جاهزة** للاستخدام في VLC وأي مشغل IPTV

## 🚀 كيفية الاستخدام

### الطريقة 1: استخدام GitHub Actions (موصى به)

1. Fork هذا المستودع إلى حسابك على GitHub
2. GitHub Actions سيقوم بتحديث القوائم تلقائياً كل 30 دقيقة
3. استخدم الملفات المحدثة من صفحة الرئيسية للمستودع

### الطريقة 2: التشغيل المحلي

```bash
# تثبيت المكتبات المطلوبة
pip install requests pycryptodome

# تشغيل السكربت
python auto_update_playlists.py
```

## 📁 الملفات الرئيسية

- `ELAHMAD_LIVE_CLEAN_100%.m3u` - القائمة الرئيسية الكاملة بجميع القنوات
- `elahmad_live_real_streams.m3u` - الروابط الحقيقية المفكوكة
- `elahmad_with_player_pages.m3u` - روابط صفحات المشغل (للتشفير اليدوي)
- `auto_update_playlists.py` - سكربت التحديث التلقائي

## 🔧 التقنية

- **Python 3.10+** مع مكتبات requests و pycryptodome
- **GitHub Actions** للتحديث التلقائي المجاني
- **فك تشفير AES-CBC** لاستخراج الروابط الحقيقية من موقع ELAHMAD

## ⚠️ ملاحظات هامة
